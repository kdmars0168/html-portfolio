# Early portfolio page — plain HTML

A single-page portfolio index linking to early practice projects, written in hand-coded HTML with no CSS framework.

Coursework from *The Complete 2023 Web Development Bootcamp*, July 2023 — the first portfolio exercise in the course.

Superseded by the current portfolio: **https://mohaimen-portfolio.vercel.app/** ([source](https://github.com/kdmars0168/Mohaimen-s-Portfolio)).

---

## What is in it

- An index page linking to the practice projects built up to that point
- Project preview screenshots
- About and contact pages

## Stack

Plain HTML. No CSS framework, no JavaScript, no build step.

## Running it

Open `index.html` in a browser.

## Why it is still here

It is kept as a starting point rather than as current work — the contrast with the React and TypeScript portfolio that replaced it is the useful part.
